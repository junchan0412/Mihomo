# Mihomo v1.25.14

本版本来自一次覆盖 Stores / Services / Views / 特权 Helper 的全量代码审查，集中修复会导致挂死、崩溃或功能静默失效的缺陷，并优化高频数据流到 UI 的路径。

## 缺陷修复

- 修复 `Shell` 与 `HelperShell` 的子进程管道死锁：此前先 `waitUntilExit()` 再读管道，子进程输出超过 64 KiB 缓冲即互相阻塞。影响 `zip -r` 备份、`zipinfo` 校验、root Helper 内的 `mihomo -t` 配置校验，以及主线程上的 `netstat` 路由采集。两份重复实现已合并为 `MihomoShared.ProcessRunner`。
- 修复订阅链接含重复 query 参数（如 `?type=ws&type=grpc`）时 `Dictionary(uniqueKeysWithValues:)` 触发的崩溃。
- 修复 Gist 备份在 Gist ID 含空格或非法字符时 `URL(string:)!` 触发的崩溃，改为提前校验并给出明确错误。
- 修复控制器请求路径被二次百分号编码：`URLComponents.path` 会对已转义的字符串再编码一次，含空格或中文的策略组/节点名（`/proxies/香港%20101/delay`）因此始终请求到错误路径，选择节点与单点测速静默失败。改用 `percentEncodedPath`。
- 修复核心异常退出后「异常退出后自动恢复」设置完全不生效的问题：核心迁移到 Helper 托管后失去进程退出回调，现由控制通道连续不可达触发恢复流程。
- 修复核心启动失败后 `isCoreRunning` 仍为 true，界面显示核心运行但进程已停止的状态不一致。
- 修复 `bootstrap()` 单一 do/catch 导致任一文件读取失败就跳过后续全部初始化：轮询不启动、自动启动核心不执行、Helper 与 Geo 状态不刷新。现按步骤隔离，单步失败只记录该步骤。
- 修复控制器刷新中单个请求失败会丢弃同一轮其余结果，导致连接表停止更新。
- 修复网络接管刷新任务句柄可能被自身清空，使 `shutdown()` 无法取消该任务并可能并发启动多个采集。
- 修复 `Formatters.trimmedMenuText` 在 `limit <= 1` 时 `prefix(limit - 1)` 越界崩溃。

## 界面修正

- 连接表「时长」列此前对没有流量的空闲连接会停止走动：该列的值由读取时的 `Date()` 计算，不参与行比较，表格因而判定该行无变化。现在时长在构建行时定型，随行一起参与比较。
- 活动页新增 `activeConnectionsRevision`：连接由「活动」转为「最近」时驱动表格重建，此前状态色不更新。
- DNS 页类型侧栏移除「本地」「系统」两项——记录全部由连接观测生成，`kind` 恒为「动态」，这两项永远筛出空表。
- DNS 页「DNS 服务器」列改名为「来源地址」：该列显示的是连接的 `sourceIP`，不是 DNS 服务器。
- 流量页搜索改用防抖后的 `appliedFilterText`，与连接页保持一致，输入时不再每个字符重算一次聚合。
- 系统代理与 TUN 工具栏按钮在对应操作进行中禁用，避免重复点击叠加特权请求。

## 稳定性与实时状态

- WebSocket 事件流改用独立 URLSession。此前复用控制器 session，其 `timeoutIntervalForResource = 15` 会截断长连接，导致实时流反复断开并退回轮询。
- 网络接管采集改为可继承取消的后台任务，`shutdown()` 能真正中止仍在执行的系统探测。
- `BoundedResponseReader` 在持锁期间写入 sink：取消与数据回调竞争时，调用方可能已经关闭并删除目标文件句柄，而委托回调仍在向该描述符写入。

## 性能

- 下载改用分块读取替代逐字节异步迭代：100 MiB Provider 下载此前需要上亿次异步迭代。
- AppKit 表格差异比较不再为每个单元格构建字符串签名，改为直接比较行值；高频连接更新下显著降低主线程开销。
- `netstat` 路由统计与 DNS 快照读取移出主线程；`networksetup` 探测按网络服务并行，接管状态刷新的子进程等待从秒级降到百毫秒级。
- 批量测速改用完成序调度，消除慢节点造成的队头阻塞并支持取消；节点延迟写入合并为约每 200 ms 一次发布，不再每个节点触发一次全策略表重渲染。
- 连接统计合并为单次遍历；策略流量样本的 24 小时修剪改为每分钟摊销一次，不再每帧全量过滤重建数组。

## 国际化与可移植性

- `networksetup`、`netstat`、`route` 的调用统一固定 `LC_ALL=C`。此前解析依赖英文标签（`Enabled:`、`Server:`、`There aren't any`），在非英文系统上会误判为「未配置代理」。
- 测速错误分类优先按 `URLError` 错误码判断，不再依赖会随系统语言变化的 `localizedDescription`。
- 落盘文件名与日志时间戳统一使用固定的 POSIX 公历格式，避免非公历日历下产生不可排序、不匹配轮转规则的文件名。
