# Mihomo v1.25.13

本版本聚焦运行稳定性、活动数据内存上限和菜单栏单实例行为。

## 稳定性与性能

- 启动时检测同一 bundle identifier 的已有 Mihomo 进程，激活已有实例并退出重复启动的进程，避免重复创建菜单栏 status item。
- 策略流量历史继续保留最近 24 小时数据，同时限制最多 50,000 条样本，避免长时间运行时内存和 SwiftUI 图表计算无界增长。
- 发布 bundle 写入 `LSMultipleInstancesProhibited`，让 Launch Services 与应用内门闩共同阻止重复实例。

## 验证

- 使用项目指定 Xcode toolchain 运行 `swift test`：240/240 通过。
- 通过 `script/ci_release_gate.sh`、应用签名校验、Release zip 校验和 update replacement smoke test。
