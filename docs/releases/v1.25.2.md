# Mihomo v1.25.2

`v1.25.2` 聚焦参考设计落地、列表一致性和主窗口切换性能。

## UI 与 UX

- 规则、配置、覆写、配置资源和日志列表统一使用 SwiftUI 内容行；相邻行使用同一语义背景，层次由行间分隔、徽标与选中态表达。
- 所有目标列表统一右侧状态、时间、刷新和更多操作列的横坐标，节点提供商与配置资源不再出现操作列漂移。
- 资源工作区按“配置资源 / 节点提供商 / 规则”分类，配置资源仅展示 Proxy Provider，规则工作区展示 Rule Provider。
- 侧边栏移除系统 List 的选中动画，采用稳定的无动画导航行；高频连接数和运行状态拆到独立 Footer，避免图标重绘闪烁。

## 性能与交互

- 规则、配置、覆写、资源、日志列表支持统一的单选、Command 多选和 Shift 范围选择。
- 页面进入时不再同步调用整份配置解析，刷新改由显式动作触发，降低切换工作区的主线程阻塞。
- 统一列表组件保留双击打开、上下文菜单、快速操作和辅助功能标签。
