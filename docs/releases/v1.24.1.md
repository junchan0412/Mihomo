# Mihomo v1.24.1

`v1.24.1` 聚焦软件更新流程的可见性、可取消性和安装安全性，基于当前最新发布基线 `v1.24.0 (78)` 递增。

## UI 与 UX

- 软件更新窗口将检查、下载、校验、准备网络、准备 Helper、安装和重启入口表达为明确阶段，用户始终能看到下一步。
- 下载阶段显示已接收字节数、总量和实时速率；支持在检查、下载和校验阶段取消，并在取消后恢复到可再次操作的状态。
- 设置、菜单栏和命令面板复用同一套更新状态与操作动作，避免重复请求和入口文案不一致。
- 只有更新包完成完整性、manifest 签名、bundle identifier 以及 App/Helper 签名校验后，才显示“重启安装”。

## 性能与稳定性

- 新增独立 `SoftwareUpdateDownloader`，使用 delegate 进度回调和受控刷新频率，避免每个网络回调都触发 UI 重绘。
- 下载、校验和安装准备共用可取消任务；失败或取消会清理临时目录，不覆盖当前 App 与 Helper。
- 更新阶段模型采用 `Sendable` 值类型跨越异步边界，降低 MainActor 状态与下载 worker 的耦合。

## 架构与测试

- `SoftwareUpdatePhase`、`SoftwareUpdateDownloadProgress` 和统一阶段文案集中在模型层，View 只负责展示与动作绑定。
- `SoftwareUpdateManager` 保留原有安全校验链，仅替换下载实现，减少更新风险。
- `swift test`：217/217 通过；`git diff --check` 通过；维护性审计覆盖 227 个 Swift 文件，0 warning、0 over-max。
- 使用 `APP_VERSION=1.24.1 APP_BUILD=79` 构建并启动 `dist/Mihomo.app`，并核查真实 bundle 的版本、build、ad-hoc 签名和启动行为。

## 无开发者账户发行说明

本版本使用 ad-hoc 签名，未经过 Apple notarization。下载、解压并移动到 `/Applications` 后，如 macOS 阻止启动，请执行：

```bash
xattr -cr /Applications/Mihomo.app
```
