# Mihomo v1.22.0

`v1.22.0` 完成桌面客户端差距分析中剩余的高频操作、路由解释和版本恢复能力，并收紧主侧栏与菜单栏的信息层级。

## 高效操作

- 菜单栏新增最近切换节点、策略组收藏、全量与单组测速；策略组和节点均显示延迟、不可用状态与当前选择。
- 测速历史保存最近结果、失败原因、跳过原因和时间；策略详情可直接查看。
- `Command-Shift-P` 打开命令面板，可导航、切换配置、执行测速、刷新资源、切换核心/系统代理/TUN、运行诊断。
- 资源页多选操作新增所选资源文件导出，并保留更新、回滚、Quick Look 与 Finder 定位。

## 可解释性与恢复

- 连接“规则 & 链路”按进程、域名、规则、策略链、出站顺序解释路由结果。
- Profile 和覆写在编辑、刷新或规则写回前创建可恢复快照；编辑器显示顶层字段差异并支持恢复。快照内容权限为 `0600`，启用 Profile Age 加密时同步加密。
- 诊断导出改名为隐私化运行健康报告，继续对配置、日志与凭据脱敏。

## 视觉修复

- 主侧栏显式使用与工作区一致的背景 token，消除系统材质叠加导致的侧栏色差。
- 菜单栏的测速入口固定在策略列表上方，状态文字与延迟颜色不再承担彼此重复的信息表达。

## 无开发者账户发行说明

本版本使用 ad-hoc 签名，未经过 Apple notarization。下载、解压并移动到 `/Applications` 后，如 macOS 阻止启动，请执行：

```bash
xattr -cr /Applications/Mihomo.app
```
