# Mihomo v1.25.10

`v1.25.10` 修复菜单栏面板外围材质断层与状态图标不可见问题。

## 菜单栏面板

- 菜单栏 window 的外围区域使用 `regularMaterial`，与内部 Liquid Glass surface 保持一致的系统材质基线。
- 保留 macOS 26 的 interactive glass surfaces，同时兼容 macOS 14 的最低部署版本。

## 菜单栏图标

- 状态栏使用 Mihomo 品牌三柱 mark 的 monochrome SwiftUI vector，避免 macOS menu bar template 渲染吞掉彩色 App icon。
- `R`、`G`、`D` 模式 badge 继续显示当前出站模式。

## 验证

- `swift build --product Mihomo` 通过。
- `swift test`：239/239 通过。
- Release bundle 启动与签名验证通过。
