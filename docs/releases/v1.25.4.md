# Mihomo v1.25.4

`v1.25.4` 聚焦资源页切换稳定性和菜单栏体验，把主窗口资源工作区与菜单栏弹窗整理成更一致的 macOS 原生操作面板。

## UI 与 UX

- 资源页进入与“配置资源 / 节点提供商 / 规则”内部切换统一使用 opacity transition，旧内容淡出、新内容淡入。
- 资源页工作区、节点提供商空态/列表和顶部计数区域使用稳定尺寸，减少不同资源子页面之间的轻微布局变化。
- 菜单栏状态图标改为模式感知徽标，可区分规则、全局、直连以及核心停止状态。
- 菜单栏下拉菜单改为分组式操作面板，增加左侧 SF Symbols、右侧状态文字、模式徽标、chevron 和快捷键提示。
- 出站模式、配置切换、打开面板和维护操作集中到菜单栏中，减少原先单行工具按钮与更多菜单的割裂感。
- 菜单栏上传下载速率开关改为通过设置保存，最近切换区域仅在有可用记录时显示。
