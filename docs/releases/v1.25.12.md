# Mihomo v1.25.12

`v1.25.12` 固定内置 Mihomo core 与 SwiftPM 依赖，补强发布包校验，并修复完整备份、远程内容大小限制和 Profile 加密迁移的一致性问题。

## 发布与依赖

- 内置 Mihomo core 固定为 `v1.19.29`，打包时验证压缩包 SHA-256、解压后二进制 SHA-256 与 `mihomo -v`。
- 提交 `Package.resolved`，避免不同机器解析出不同的 Yams 版本。
- CI release gate 检查 bundle 和 Release zip 中的 core 是否存在、版本和 SHA-256 是否匹配。

## 数据与安全

- 普通备份完整保存可恢复的 settings 与 Profile 内容，包括代理凭据；备份应保存到可信位置。
- WebDAV、Gist、远程 Profile、远程覆写和 Provider 下载增加响应大小上限，并在流式接收阶段拒绝超限内容。
- Profile 加密切换改为 staging、原子安装和失败回滚，避免多 Profile 迁移后留下混合加密状态。

## 验证

- 使用项目指定 Xcode toolchain 运行 `swift test`：240/240 通过。
- `script/prepare_core_bundle.sh` 通过固定 core 版本与 hash 校验。
