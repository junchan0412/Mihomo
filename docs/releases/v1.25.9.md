# Mihomo v1.25.9

`v1.25.9` 持续修复菜单栏的品牌一致性与 macOS 原生材质表现。

## 菜单栏图标

- 菜单栏状态 glyph 直接复用 `AppBrandIcon` 的 SwiftUI 矢量 mark，与 Dock/App 图标保持同一组三柱信号视觉资产。
- 出站模式字母仍作为状态 badge 显示；核心停止时图标自动降低饱和度与不透明度，避免把停用状态误读为正常运行。

## Liquid Glass 菜单面板

- 菜单栏下拉窗口移除整块 `ultraThinMaterial` 与蓝紫渐变背景，改由共享 `GlassEffectContainer` 管理状态头部和菜单内容表面。
- macOS 26 及以上使用 `.glassEffect(.regular.interactive())`，菜单内容具备系统 glass 的自适应折射、高亮和交互反馈。
- macOS 14/15 使用 `regularMaterial` 与轻量描边 fallback，保持项目最低系统版本与现有操作路径兼容。
