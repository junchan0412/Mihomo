# Mihomo v1.25.8

`v1.25.8` 修复 Provider 资源批量更新中同路径并发写入和历史文件权限导致的刷新失败。

## Provider 更新可靠性

- 批量更新以规范化后的 Runtime 目标路径去重。Profile Provider 与 Node Provider 指向同一文件时，只会执行一次刷新，避免并发覆盖同一资源。
- 文件替换改为在目标目录创建 staging 文件，写入并同步后通过 POSIX `rename` 原子替换，再同步目录元数据。
- 即使旧 Provider 文件曾被 mihomo core 以 `root` 身份创建，客户端也不再依赖原文件可写；只要目标目录可写，刷新即可完成。

## 安全边界

- 保持原有的路径隔离、内容验证、SHA-256 摘要、备份与回滚机制。
- HTML 错误页、空内容和不符合 Provider 结构的数据仍会被拒绝，旧资源不会被异常响应覆盖。
