# Mihomo v1.25.11

`v1.25.11` 统一菜单栏 Liquid Glass 视觉，修复状态栏矢量图标在 template label 中被压缩的问题，并修复 ad-hoc 更新流程的 Helper entitlement 错误。

## 菜单栏窗口

- 菜单栏 window 外层使用 `.containerBackground(.regularMaterial, for: .window)`，与内部 Liquid Glass surfaces 使用同一系统材质基线。
- macOS 14 使用 `.background(.regularMaterial)` fallback，保留最低部署版本兼容性。

## 菜单栏图标

- 菜单栏入口直接复用 Mihomo 软件图标的三柱矢量 mark，固定为 19×19，继续叠加 `R`、`G`、`D` 模式 badge。

## App 内更新

- ad-hoc/legacy Helper 模式下跳过不具备 entitlement 的 `SMAppService.unregister()` 调用，避免出现 `Requestor lacks required entitlement`。
- 更新安装脚本使用普通 `/usr/bin/open` 启动替换后的 App，避免强制新开实例。

## 验证

- `swift build --product Mihomo` 通过。
- `swift test`：239/239 通过。
- `APP_VERSION=1.25.11 ./script/build_and_run.sh --verify` 通过。
