# Mihomo v1.25.3

`v1.25.3` 聚焦主窗口页面切换体验，在保持 `v1.25.2` 列表性能和稳定导航结构的基础上，为详情工作区加入轻量淡入淡出过渡。

## UI 与 UX

- 主窗口详情区在 `AppSection` 变化时使用 opacity transition，旧页面淡出、新页面淡入，避免工作区切换时出现突兀闪变。
- 页面过渡只作用于详情内容，不改变侧边栏、Toolbar、菜单栏状态和既有页面布局。
- 动画遵守 macOS “减少动态效果”辅助功能设置；用户开启后页面仍保持即时切换。
