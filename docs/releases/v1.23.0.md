# Mihomo v1.23.0

`v1.23.0` 集中改善主要工作区的空状态、选区一致性、窄窗口操作、隐私展示和高频数据刷新，并将大型实现按职责拆分为可测试、可持续维护的边界。

## UI 与 UX

- 连接、DNS、流量统计、概览时间轴、配置、覆写、规则、日志和资源在无数据或无匹配结果时显示明确空状态，不再初始化没有内容的 AppKit 表格。
- 搜索与筛选变化会统一执行 selection reconciliation；隐藏行不再继续驱动详情面板、操作按钮或批量动作。
- 覆写列表的刷新与添加操作整合为紧凑菜单，窄窗口仍保留导出与删除入口。
- 命令面板与系统代理不再占用冲突的快捷键；列表、详情与问题定位行为保持一致。
- 策略搜索、可用性与延迟筛选会移除没有可见候选项的空组，避免出现无法操作的展开区域。

## 性能

- Activity 连接表由 `connectionsRevision` 与 `recentConnectionsRevision` 驱动刷新，避免每轮更新重新拼接完整行 fingerprint。
- 日志 presentation 行只在日志批次、分类或搜索条件变化时重建。
- Activity 流量统计在一次样本遍历中聚合今天、5/15/60 分钟和 6/12 小时窗口；概览时间轴通过二分定位可见区间后单次分桶。
- 策略、资源、规则、Profile 与覆写页面分别使用单个 presentation snapshot 派生列表、摘要、选区、表高与 columns，避免同轮渲染重复扫描。
- AppStore 的相同值发布受到抑制，减少无实际状态变化时的观察链刷新。

## 架构与可维护性

- `AppStore.swift` 从 403 行缩减到 125 行，仅保留共享低频状态、service 与 task ownership；bootstrap、派生状态、运行时 store proxy 与策略图标预加载迁入独立 extension。
- `AppSettings`、Config Fragment、Node Provider、软件更新、Controller 解析、Profile runtime config、配置质量报告和 Helper metadata/LaunchDaemon 等模型与服务按职责拆分。
- AppKit table 的 model、生命周期、键盘交互与 cell factory 分文件维护，selection、checkbox、右键菜单和 accessibility 契约保持不变。
- 资源、规则、覆写与 Activity 的表格、header、bottom bar、空状态和行展示从工作区协调代码中拆出；迁移后不再使用的 Profile 覆写摘要视图已删除。
- 维护性审计覆盖 221 个 Swift 文件：0 个 warning、0 个 over-max；所有文件均不超过 350 行，最大文件为 `MenuBarView.swift`（347 行）。

## 安全与隐私

- Profile、覆写与 Provider 的远程来源展示统一移除 user/password、query 与 fragment。
- 高熵 path token 会被隐藏，同时保留描述性仓库路径和常见配置文件名；下载仍使用原始 URL。
- 脱敏逻辑应用于界面、截图与 accessibility tree 可见文本，避免凭据经展示层泄露。

## 测试与验证

- 211 个 XCTest 覆盖 Activity/日志展示缓存、流量聚合、时间轴、空状态、selection reconciliation、URL 脱敏、策略/资源/规则/Profile/覆写 presentation snapshot、规则 draft、AppStore 派生状态及既有安全与更新流程。
- `git diff --check` 通过。
- 维护性审计为 0 warning、0 over-max。
- 使用 `APP_VERSION=1.23.0 APP_BUILD=77` 构建并核查 `dist/Mihomo.app`，逐页 UI smoke 以该绝对路径为准。

## 无开发者账户发行说明

本版本使用 ad-hoc 签名，未经过 Apple notarization。下载、解压并移动到 `/Applications` 后，如 macOS 阻止启动，请执行：

```bash
xattr -cr /Applications/Mihomo.app
```
