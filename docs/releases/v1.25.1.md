# Mihomo v1.25.1

`v1.25.1` 基于远端最新发布基线 `v1.25.0 (80)`，聚焦节点提供商同步一致性、窗口背景统一和维护性收口。

## UI 与 UX

- 主窗口侧栏使用 plain list 与统一页面底色，NavigationSplitView 采用 balanced 布局，窗口 Toolbar、侧栏和内容区保持同一视觉平面。
- 卡片改用稳定的语义背景色，减少浅色/深色模式下由透明材质叠加导致的色差。
- 清理大区域间不必要的分割线，并保留侧栏收藏、折叠分区、连接入口与状态摘要。

## 一致性与可靠性

- 从节点提供商列表删除 Provider 时，同步从关联 Profile 的 `proxy-providers` 中删除对应条目。
- Provider/Profile 同步继续保留配置格式、注释和尾换行；新增删除、更新、保留路径的回归测试。
- 同名 Provider 规范化与 Profile 双向同步逻辑拆分为独立模型文件，降低后续维护成本。
