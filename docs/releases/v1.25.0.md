# Mihomo v1.25.0

`v1.25.0` 基于已核实的最新发布基线 `v1.24.1 (79)`，聚焦 UI/UX、批量任务可取消性、网络接管安全、Provider 原子替换、设置输入可靠性和维护性。

## UI 与 UX

- Activity 搜索加入 200ms debounce；筛选后自动清理隐藏选区，批量关闭使用有界并发并保持结果可解释。
- 网络页面展示最近检查时间、未知状态和操作进度；系统代理、DNS、TUN 操作期间禁用重复入口，TUN 路由恢复失败默认停止后续关闭动作，并提供强制关闭确认。
- 设置页面新增字段级错误提示，覆盖端口冲突、并发/超时范围、HTTP(S) URL、DNS、IP/CIDR 和自定义更新 manifest。
- 网络页面按概览、DNS、恢复和域名嗅探拆分职责；更新 manifest 校验、网络接管状态和页面子区分别独立文件，降低维护成本。

## 性能与稳定性

- Provider 下载先写入 staging 文件并 `fsync`，通过内容解析、条目计数和 SHA-256 校验后再原子替换；失败时保留并恢复旧文件。
- Provider 内容校验拒绝 HTML 错误页、空文件、空顶层映射和无有效条目的 YAML/Base64 内容。
- 批量 Provider/Profile 刷新支持线程安全取消、去重、互斥和 generation 保护；取消后停止派发新任务，旧自动刷新不会覆盖新状态。
- 网络接管读取失败标记为 `unknown` 而不是误报 `failed`，并保留最近检查时间。

## 更新与发布安全

- 软件更新支持受信任的 HTTPS manifest 镜像；镜像不可用或校验失败时回退 GitHub Releases。
- 更新包仍必须通过内置 Ed25519 公钥、SHA-256、bundle identifier、App/Helper signing identifier 以及 ad-hoc CDHash 或 Developer ID Team 校验。
- 未接入 Developer ID；本版本继续使用 ad-hoc 发布模式。
