# Mihomo v1.25.7

`v1.25.7` 更新应用品牌图标、菜单栏图标和菜单栏下拉菜单的视觉语言。

## 视觉系统

- App 图标改为深色/浅色两套玻璃质感圆角底，使用蓝青到紫色渐变的三柱信号 mark，加入高光和轻微光晕以保持在 Dock、Launchpad 和更新窗口中的识别度。
- 菜单栏 template 图标与 App mark 保持一致，状态 glyph 继续显示出站模式字母和核心运行状态。
- 菜单栏下拉菜单改用 `ultraThinMaterial`，顶部增加 Mihomo 状态头部和实时流量速率，行项目使用连续圆角 hover 表面，分隔线和分组顺序保持原有操作语义。
