# Mihomo v1.25.5

`v1.25.5` 修复节点提供商对常见订阅格式的兼容性，并按照 macOS 原生菜单栏工作流重构了菜单栏操作面板。

## 节点提供商

- 支持 Clash YAML、Base64 YAML、Base64 与 URL-safe Base64 节点链接订阅。
- 可将常见 SS、VMess、Trojan、VLESS、Hysteria2 与 TUIC 分享链接转换为 Mihomo Provider YAML。
- 支持 SIP002 Shadowsocks 链接中的 Base64 凭据。
- 订阅响应为 HTML 错误页时保留旧 Provider 文件，并明确提示 404 URL 可能已失效。
- HTTPS 证书校验失败会指出订阅站点证书异常；应用不会降低 TLS 校验要求。

## 菜单栏

- 菜单栏改为紧凑的原生分级面板：每个策略组展示当前节点和延迟，点击后进入节点选择菜单。
- 增加活跃客户端流量概览、系统代理、TUN、终端代理命令复制、功能、模块、面板、配置切换、重载配置及检查更新入口。
- 常用状态与操作按参考布局重新分区，减少长列表和重复控制项。
