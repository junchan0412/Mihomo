# Mihomo v1.25.6

`v1.25.6` 按照 macOS 菜单栏工作流重构高频代理操作入口，并强化节点提供商异常订阅的安全诊断。

## 菜单栏

- 顶级顺序调整为：显示主窗口、出站模式、策略组、设置为系统代理、TUN 模式、复制终端代理命令、功能面板、覆写列表、更新外部资源、切换配置和重载配置。
- 策略组直接显示当前节点及其延迟；打开二级菜单时，顶部“延迟测试”可测试该组，下面按节点展示选择状态和对应延迟。
- 移除菜单栏中的活跃连接长列表，让代理控制项保持稳定顺序。
- 功能面板集中核心启动/停止、全量测速、订阅刷新和主窗口常用页面入口。

## 覆写与外部资源

- 原“模块”菜单改为“覆写列表”，只显示可应用于当前配置的覆写，并以勾选状态表示是否启用。
- 点击覆写后立即保存；当核心正在运行，自动重载核心使新覆写即时生效。
- “更新外部资源”改为独立顶级操作，批量任务进行中会禁用重复触发。

## 节点提供商诊断

- 保持严格 HTTPS 校验：证书域名、有效期或信任链异常会明确提示，应用不会绕过 TLS 验证。
- 订阅返回 HTML 错误页（例如 404）或非 Provider 内容时继续保留旧文件，避免失效响应破坏现有节点。
- 本次排查的 `liangxin.xyz` URL 在正常 TLS 校验下证书域名不匹配；只读诊断中忽略校验后服务端仍返回 HTML `404 Not Found`，因此它不是可安全导入的节点订阅。请向服务商索取有效、证书匹配的订阅地址。

## 测试与质量

- 新增菜单栏层级、策略组二级菜单和覆写即时生效的回归断言。
- `swift test`、发布门禁和 ad-hoc release smoke test 均在发布前执行。

## 发布说明

本版本沿用仓库既有 ad-hoc 发布流程，未经过 Apple notarization。若 macOS 阻止启动，可执行：

```bash
xattr -cr /Applications/Mihomo.app
```
