# Mihomo v1.22.1

`v1.22.1` 修复 `v1.22.0` 中版本差异与命令面板键盘操作的两个实际交互问题。

## 版本历史

- 覆写快照改为按 `ConfigFragment` 结构比较，准确列出新增、删除和内容/状态/类型/作用范围/来源变化。
- Profile 仍按 YAML 顶层字段比较；无法解析的内容会明确回退为“内容”变更，避免误报无差异。

## 命令面板

- 命令项使用稳定 ID，筛选和重绘后仍保留正确的选中状态。
- 搜索框聚焦时支持上/下箭头选择、Enter 执行和 Esc 关闭。
- 已通过实机验证：筛选“诊断”后可用方向键选择并用 Enter 跳转诊断页。

## 验证

- `swift test`
- `git diff --check`
- `./script/build_and_run.sh --verify`
- `MIHOMO_ALLOW_UNNOTARIZED_RELEASE=1 ./script/package_release.sh 1.22.1`
- `MIHOMO_ALLOW_UNNOTARIZED_RELEASE=1 ./script/release_smoke_test.sh 1.22.1`

## 无开发者账户发行说明

本版本使用 ad-hoc 签名，未经过 Apple notarization。下载、解压并移动到 `/Applications` 后，如 macOS 阻止启动，请执行：

```bash
xattr -cr /Applications/Mihomo.app
```
